# Student Study Planner 🎓

A comprehensive Android application designed to help students organize their academic life, manage tasks, and access study materials efficiently.

## ✨ Features

*   **Task Management:** Keep track of your assignments, exams, and daily to-dos.
*   **Notes Organizer:** Create and manage study notes for different subjects.
*   **Document Viewer:** Integrated PDF viewer to read study materials directly within the app.
*   **AI Study Assistant:** Integrated AI features to provide quick responses and help with study queries.
*   **Personal Profile:** Manage your student profile and academic details.
*   **Intuitive Navigation:** Easy-to-use bottom navigation for quick access to all sections.

## 🛠️ Tech Stack

*   **Language:** Kotlin
*   **UI Framework:** XML with Material Design 3
*   **Architecture:** MVVM (Model-View-ViewModel)
*   **Navigation:** Jetpack Navigation Component
*   **View Binding:** For safe and efficient interaction with UI elements.
